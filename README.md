### Project Description
[ശിലായുഗം (Stone Age) is a lighthearted, aesthetic web application dedicated to the sincere art of rating and appreciating rocks.

Key Highlights:
Community Leaderboard & Feed: Rocks are ranked on a podium based on likes, alongside a reverse-chronological browsing feed.
Specimen Submissions: Users can submit custom photos of rocks with geological names and captions.
Card Management: Includes full like/unlike functionality, removal controls, and browser localStorage persistence.
Interactive Easter Eggs:
Hovering over "rock" in the hero headline morphs the word into "കല്ല്".
Hovering over the top-right boulder reveals Dwayne "The Rock" Johnson.
Tech Stack: Built with pure HTML5, CSS3 (responsive grid/flexbox, custom earth-toned palette, and Fraunces serif typography), and vanilla JavaScript.
]

### The Problem (that doesn't exist)
[The Problem: 4.5 Billion Years of Unreviewed Minerals
For four and a half billion years, Earth’s rocks have endured tectonic collisions, blistering magma chambers, and relentless glacial erosion—only to sit on the ground completely unrated.

Food has Yelp.
Pets have Instagram.
Strangers on the internet have LinkedIn endorsements.
Yet a perfectly round basalt pebble or a dignified chunk of red sandstone has had zero quantitative feedback on its heft, posture, or charisma.

The Solution: ശിലായുഗം
This project boldly solves the profound absence of unnecessary democratic mineral appraisal:

Gives neglected driveway stones their rightful time on a digital podium.
Allows the public to solemnly debate stone symmetry with complete sincerity.
Ensures nobody confuses an ordinary granite boulder with Dwayne "The Rock" Johnson without at least hovering over it first]

### The Solution (that nobody asked for)
[By giving rocks the full influencer treatment: 🪨✨
The Podium of Glory 🏆: Gravel competes for clout. If a stone has good posture, the internet taps the heart and crowns it #1.
The "Submit a Rock" Pipeline 📸: Find a handsome driveway pebble? Upload it, name it ("Big Craig", "Red Sandstone"), and let the world judge.
Linguistic Magic 🪄: Hover over "rock" and it instantly morphs into "കല്ല്" for extra ancient stone energy.
The Secret Flex 💪: Hover over the hero boulder and Dwayne "The Rock" Johnson appears to personally validate your mineral choices.]

## Technical Details
### Technologies/Components Used
For Software:
- [HTML5: Semantic document structure, modal layouts, inline SVG icons.
CSS3: Custom CSS variables, Flexbox & Grid layouts, animations, transitions, and responsive design.
JavaScript (ES6+): Dynamic DOM manipulation, event handling, and interactive hover effects.
Python: Image format inspection, Base64 conversion, and local file automation.]
- [None / Vanilla: Intentionally built framework-free for ultra-lightweight, zero-dependency browser performance.]
- [Google Fonts: Fraunces (classic serif for stone branding) and Work Sans (modern sans-serif for UI readability).
HTML5 Web APIs: localStorage (persistent rock submissions & likes) and FileReader API (drag-and-drop client-side photo processing).
Python Standard Library: http.server, base64, shutil.
Pillow (PIL): Image metadata and dimension validation.]
- Python 3 http.server: Local HTTP development server.
Windows PowerShell: Process management and command-line execution.
Modern Web Browsers (Chrome / Edge): Real-time UI rendering and testing.]

For Hardware:
- [Header & Brand: Sticky bar with ശിലായുഗം branding and quick navigation.
Interactive Hero Stage: Headline that morphs "rock" 
→ "കല്ല്" and a boulder that reveals Dwayne Johnson on hover.
Podium & Leaderboard: Top 3 ranked stones with podium bases, plus a ranked list.
Browse Feed: Grid of stones with like counts, timestamps, and remove buttons.
Upload Modal: Drag-and-drop photo uploader with name and caption inputs.
]
- [Architecture: Zero-dependency, client-side Single-Page App (SPA).
Storage: Browser localStorage for rocks, likes, and removals.
Design & Fonts: Earth-toned palette with Google Fonts Fraunces & Work Sans.
Responsive: Mobile-friendly CSS Grid and Flexbox layouts.]
- [Web Browser: Chrome, Edge, Safari, or Firefox.
Local Server: Python 3 (python -m http.server 8080) or any static host.
Editor / Terminal: VS Code and PowerShell / Bash.]
